StretchText Page

A browser extension that brings stretchtext (Ted Nelson, 1967) to any web page:

“A monad is a type that wraps values.”
one click → “In programming, a monad is a generic type that wraps values, and it lets you chain steps that each take a plain value and return a wrapped value.”

  • Select any phrase, click ⬡ Stretch — the model writes more detail that grows in place.
  • Click the highlighted phrase to collapse it back.
  • Bring your own Pollen: generate a key at enter.pollinations.ai/keys and paste it in the options.
